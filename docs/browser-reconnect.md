# 网页退出与重连

本行为以应用后端进程持续运行、浏览器仍保留本站存储为前提。

- 关闭网页、刷新、退出登录只断开实时订阅，不取消已接收的 Agent 或工具任务。
- Agent 连接快照包含消息、运行状态、重试、模型、待确认请求、最新部署流程与下载状态。下载完成事件在离线期间发生也可以恢复。
- 全局 Agent 的实例跳转保留到浏览器成功切换后确认收到；旧跳转的回执不能清除新跳转。
- 危险操作确认和选择题等待明确回答或取消，不因用户离线而自动超时。未确认不会自动批准。
- 消息先写入浏览器待发送列表，再通过独立的短 HTTP 请求提交。后端按会话与请求标识去重；收到回执才移除待发送记录。重开页面会恢复并重试，用户也可以移除待发送记录。移除不等于取消已运行任务。
- 同一浏览器保留当前实例、总览/实例页面、移动端标签、每个实例的聊天草稿、待发送附件引用、文件目录、控制台输入及历史、文件编辑草稿、打开的配置表单和提示词草稿。选择题未提交的选项按问题标识恢复。
- 浏览器文件上传仍依赖页面连接；上传期间关闭页面会触发浏览器离页提醒。强制退出无法保证上传完成，没有断点续传。已经上传成功的附件引用和槽位文件可以恢复。
- 控制台重连显示最近的日志快照，数据库里的完整日志不因网页退出而删除。

浏览器存储被清空、被禁用或配额不足时，本地草稿与待发送列表无法保证保存。此机制不提供后端重启后的消息去重或任务恢复保证。
